# Paper1 Revision Evidence (2026-11-08)

This directory archives the completed revision experiments for the SFR-SAC Paper1 resubmission.

## Contents

- `STRONG_EVIDENCE_SUMMARY.md`: paper-facing summary focused on the primary evidence;
- `data/REVISION_REPORT.md`: complete runner report for the container stages;
- `data/fair_critics_local_report.md`: complete local five-pair Fair Critics report;
- `data/`: protocol, manifest, suite status, and provenance files;
- `tables/`: CSV and LaTeX tables for Fair Critics, model mismatch, CPO, horizon, penalty form, AP, and latency;
- `figures/`: publication figures generated by the repository plotting script.

The primary narrative selects experiments by their direct relevance to the paper questions. The complete stage tables remain archived and are not replaced by the short summary.

## Reproducibility

The code used by these experiments is included in the repository under `revision/`, `run_revision.sh`, and `run_remaining.sh`. The frozen protocol is documented in `EXPERIMENT_PROTOCOL.md`.

The container stages used the physical CPU-cycle and PA/circuit energy models, AP-dependent channel gains, `N=70` for the revision controls, the declared paired seeds, and 1,600 training episodes. The local Fair Critics stage used five paired deployments; the container controls used the pair counts declared in the protocol.
